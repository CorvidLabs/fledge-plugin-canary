# Context

The SpecSync lifecycle requires meaningful source and governance changes to be
covered by an approved change. Canary installs generated guidance for Claude,
Codex, Cursor, and Gemini, but those directories are absent from the meaningful
path set. CHG2 already covers all four integrations plus lifecycle path coverage,
while its supporting context and docs describe only three integrations.
